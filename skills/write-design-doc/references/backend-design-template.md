# 后端详细设计文档模板

使用本模板将需求分析或概要设计思路转成可实现的后端详细设计文档。章节内容必须具体；确实无关的章节可以删除，但不要保留空占位。

输出时必须把本模板的示例内容替换为真实设计；不得原样保留空表格、示例 JSON、示例 Mermaid 或示例伪代码。确实无关的章节直接删除。

### 2.1 业务背景

### 2.2 后端设计目标

- 需要新增、保存或变更的数据。
- 需要暴露的 API。
- 需要复用的现有服务或能力。
- 一致性、权限、租户、审计等要求。

### 2.3 非目标范围

说明本设计明确不处理的内容，例如前端布局、离线迁移脚本、历史数据清理或未来流程扩展。
